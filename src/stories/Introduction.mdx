## Как использовать

```tsx
import { Button } from 'mds'

<Button variant="primary" size="md">
  Сохранить
</Button>
```

Подключить токены в проект:

```css
@import 'mds/styles/tokens.css';
@import 'mds/styles/reset.css';
```
